# ДентаЛайн

Адаптивная демонстрационная страница стоматологической клиники. React, TypeScript, Vite, GSAP и ScrollTrigger.

## Запуск

```sh
npm ci
npm run dev
```

Продакшен-сборка: `npm run build`. Просмотр сборки: `npm run preview`.

## Содержание и данные

Все тексты интерфейса на русском. Данные специалистов демонстрационные, фотографии с Unsplash иллюстрируют концепцию, а не реальную клинику. Адрес, телефон, часы работы и социальные ссылки намеренно ожидают подтверждённых данных. Цены и медицинские гарантии не заявлены.

Форма проверяет заполнение средствами браузера. Отправки, хранения данных и реальной записи нет. Перед запуском необходимо подключить backend, реальные контакты и утверждённую политику обработки данных.

Изменяемые данные услуг и врачей находятся в `src/main.tsx`, палитра и адаптивные стили — в `src/style.css`. Векторный логотип использует currentColor и поддерживает светлые и тёмные фоны.

GSAP учитывает reduced motion и очищает ScrollTrigger при размонтировании. Изображения и шрифты требуют доступа к внешним серверам.

## Публикация на GitHub

Проект подготовлен как отдельный Git-репозиторий с веткой `main`.
Создайте пустой репозиторий на GitHub без README и `.gitignore`, затем выполните в папке проекта, заменив `YOUR_REPOSITORY_URL` адресом репозитория:

```sh
git remote add origin YOUR_REPOSITORY_URL
git push -u origin main
```

Зависимости, сборки, локальные настройки, секреты и служебные папки ИИ исключены через `.gitignore`. Для запуска после клонирования: `npm ci`, затем `npm run dev`.

## GitHub Pages

Сайт публикуется по адресу https://giposfila.github.io/DentaLine-Landing/.

1. В настройках репозитория откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions** вместо **Deploy from a branch**.
2. Отправьте изменения с `.github/workflows/deploy.yml` в ветку `main`.
3. Дождитесь успешного workflow **Deploy to GitHub Pages** на вкладке **Actions**. Для повторного запуска используйте **Run workflow**.

Workflow использует Node.js 24, выполняет `npm ci` и `npm run build`, затем публикует только `dist/`. Публикация исходников из корня ветки без сборки не работает: браузер не собирает модули Vite.

В production настроен базовый путь `/DentaLine-Landing/`; локальный `npm run dev` работает от `/`. Проверка production-сборки: `npm run build`, затем `npm run preview` и открытие `http://localhost:4173/DentaLine-Landing/`. Для своего домена или другого имени репозитория измените `base` в конфигурации Vite.
